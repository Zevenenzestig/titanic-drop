# Titanic Drop

Приложение с двумя страницами. Шанс выжить считается по реальным
пассажирам из `train.csv` (данные уже встроены в приложение).

## Запуск
1. Установите зависимости (один раз):

       python -m pip install -r requirements.txt

2. Запустите приложение:

       python app.py

Если `python` не запускается, используйте полный путь, например в PowerShell:

    & "C:\Users\ИМЯ\AppData\Local\Programs\Python\Python312\python.exe" app.py

Если `pywebview` не установлен, приложение откроется в браузере.
На Windows окну нужен Microsoft Edge WebView2 (обычно уже установлен).

## Страницы
- **Прогнозирование** — введите класс, пол, возраст, цену билета и
  родственников, чтобы увидеть шанс выжить.
- **Titanic Drop** — вам выдают пассажира (20 лет, мужчина, 3 класс, без
  родственников). Улучшайте класс, пол и возраст: по 3 попытки на каждое.
  Неудача ухудшает пассажира. «Отправить в рейс» разыгрывает судьбу и
  выдаёт нового пассажира.
