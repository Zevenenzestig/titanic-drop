# Titanic — прогноз выживания

## 1. Установка библиотек
Откройте терминал в папке проекта и выполните:

pip install -r requirements.txt

## 2. Обучение модели
Запустите:

python train_model.py

После этого появится файл:
titanic_model.pkl

В консоли будет показана точность модели.

## 3. Запуск интерфейса
После обучения запустите:

python app.py

Откроется окно программы, где можно ввести данные пассажира и получить прогноз.

## Используемые признаки
- Pclass — класс билета
- Sex — пол
- Age — возраст
- SibSp — братья/сёстры/супруги
- Parch — родители/дети
- Fare — стоимость билета

Целевая переменная:
Survived — 0 = не выжил, 1 = выжил.

Модель:
Random Forest Classifier.
