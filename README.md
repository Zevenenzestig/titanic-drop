# Titanic Drop

## Запуск приложения (окно с тем же интерфейсом, что и на сайте)
1. pip install -r requirements.txt
2. python app.py

Интерфейс — titanic_drop.html, он показывается в собственном окне
(pywebview). Если pywebview не установлен, страница откроется в браузере.
На Windows нужен Microsoft Edge WebView2 (обычно уже установлен).

## Страницы
- Прогнозирование: класс, пол, возраст, цена билета, родственники — шанс выжить.
- Titanic Drop: пассажир (20 лет, мужчина, 3 класс, без родственников).
  Улучшайте класс, пол и возраст, по 3 попытки на каждое. Неудача ухудшает
  пассажира. «Отправить в рейс» разыгрывает судьбу и выдаёт нового пассажира.

Шанс выжить считается по реальным пассажирам из train.csv (данные вшиты
в titanic_drop.html), без запуска модели.
